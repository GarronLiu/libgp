offline Training via Stochastic Variation Gaussian Process with Automatic Inducing point selection
Input:	USV maneuvering state-input trajectories {x_i | x_i = [u_i v_i r_i tl_i, tr_i}^N_i=1, Smoothed Residual dynamics trajectories {a_res_i| a_res_i = [a_udot, a_vdot, a_rdot]^T}^N_i=1, initial hyperparameters for ARD kernel
Initialize:  a candidate set of M inducing points randomly sampled from original training data
Pre-fitting:
	while iter < iter_max do
	   calculate sparse GP approximation with inducing points {}
	   calculate ELBO L(Z) with eq. ()
	   calculate gradient of hyperparameters with automatic differentiation
	   update hyperparameters
	end while
Pruning:
	while iter < iter_max do
	   sample a subset of inducing points according to Point Process eq. ()
	   calculate ELBO L(Z) with eq. ()
	   calculate gradient of variational parameters with score function estimation, eq. ()
	   update variational parameters
	end while
	execute truncate on the inducing points of low informativeness
Post-fitting:
	while iter < iter_max do
	   calculate sparse GP approximation with the truncated inducing point set {}
	   calculate ELBO L(Z) with eq. ()
	   calculate gradient of hyperparameters with automatic differentiation
	   update hyperparameters
	end while
